M2n: 消除拖动/拉伸松手后的闪烁

两个独立原因：

1) 模型比 XML 晚一帧（useDeferredValue）
   松手时立刻 setGeomLive(null) 撤掉预览，但渲染模型走 parsedXml = useDeferredValue(xml)，
   还没更新 → 先按旧几何画一帧（弹回原位），下一帧才跳到新位置 = 肉眼看到"闪一下"。
   修：松手时不撤预览，改为「等模型落地再撤」——
   XmlCanvas 加 useEffect(() => setGeomLive(null), [node])：node 是模型产出的对象，
   它换新就说明写回的几何已经进 DOM；再加 400ms 兜底定时器（拖 0px / 写回被拦时自清）。

2) match_parent（百分比）元素移动时预览宽度不变，落盘后却被扣窄
   渲染层对 match_parent + margin 用 calc(100% - Npx)。拖动预览只改 marginLeft，
   浏览器不会重算 calc → 松手后模型一算，宽度立刻少掉 margin 那么多 → 又闪一下。
   （实测：拖 60px 后 516px → 456px）
   Android 语义下 match_parent + margin 确实会扣宽，所以修法是让预览同步缩：
   beginGeom 记录 wPct/hPct（inline style 含 %），move 时 if (wPct) w -= dx，
   预览再把百分比宽/高换成同值 px。

测试：xml_m2k 新增 M2n 用例 4 项（百分比宽/高移动同步缩、固定宽不缩、缩放画布换算）

实测（CDP 合成 pointer 事件 + rAF 逐帧采样）：
  up 之后逐帧宽度 456/456/456… 恒定，无回弹、无双跳
