M2p: RelativeLayout 完整定位规则 + CL/RL 子项可拖改宽高

1) lib/xml/relative.ts（新增）：RelativeLayout 求解器
   支持 Android 全量常用规则：
   - alignParentStart/Left/End/Right/Top/Bottom
   - centerInParent / centerHorizontal / centerVertical
   - toStartOf/toLeftOf/toEndOf/toRightOf、above/below
   - alignStart/Left/End/Right/Top/Bottom（对齐兄弟的边）
   - margin（分边优先，layout_margin 兜底）、match_parent 扣 margin、wrap 用 estSize
   - 兄弟缺失回落 parent、循环引用断环 + warn

2) css.ts：RL 接入渲染（display:block + relative，子项 absolute）
   ⚠ 顺手修了 CL/RL 共有的 padding 偏移 bug：
   CSS absolute 定位基准是 padding box 外沿（不含 padding），而 Android 是在
   padding 里面排子项 → 子项坐标 +padL/padT、内容区 -padding，两边都修。
   （之前 CL 根布局 padding=16dp 时子项其实贴在 padding 外侧，与真机不一致）

3) XmlCanvas：CL/RL 子项的「改宽高」手柄
   - 手柄画在边内侧（紫色，避开外侧的约束圆点）
   - right/bottom 总是可写 layout_width/height
   - CL 的 left/top 只有锚了 start/top 才给（marginStart 才有用）
   - RL 四个都给，但 move 只写推得动的轴（end 对齐的子项 marginStart 推不动）
   - 预览改 absolute left/top（margin 已被折进去），与落盘一致不闪

测试：新增 16 项 RL 用例（含 padding、循环引用、match_parent+margin），全量 1041 绿
