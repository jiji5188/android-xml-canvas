# android-xml-canvas 界面交互设计（UI/UX 规格）

> 版本：v1.0（2026-10-31）
> 视角：把本工具当**开发工具的前端**来做（对标 Android Studio Layout Editor / Figma / Webflow 的操作手感），而不是当「能点的网页」。
> 判据只有一条：**熟练用户能不能不看说明、不摸鼠标找按钮，就把界面改完并保存。**

---

## 0. 六条硬原则

| # | 原则 | 落到 UI 上 |
|---|---|---|
| 1 | **主操作永远可见** | 保存 / 运行 / 切预览-代码 / 撤销重做，任何尺寸下都在一屏内，不藏进「更多」 |
| 2 | **选中是全局状态** | 画布选中 = 图层树高亮 = 属性面板内容 = 代码行高亮，四处永远同步（现在缺代码行） |
| 3 | **危险操作可逆** | 删除/清空/覆盖一律进撤销栈 + 3 秒 toast 带「撤销」按钮，不要二次确认弹窗（弹窗打断心流） |
| 4 | **能键盘就别点** | 所有面板可 Tab 到达；高频操作有单键快捷键；焦点环永不隐藏 |
| 5 | **空态要教人** | 每个面板空的时候不是「暂无数据」，而是「下一步做什么 + 一个按钮」 |
| 6 | **失败要给出路** | 报错必须带：原因 + 在哪一行 + 一个修复动作（跳转/重试/回滚） |

**尺寸基线**：图标按钮 32×32（桌面）/ 44×44（移动）；行高 28（紧凑）-36（舒适）；间距刻度 4/8/12/16/24；圆角 8/12；动效 150–220ms ease-out；焦点环 2px 主色 + 2px offset。

## 1. 全局框架

### 1.1 区域划分（桌面 ≥1280）

```
┌──────────────────────────────────────────────────────────────────────┐
│ Toolbar  设备▾ 缩放──●  ↶↷ │ 保存 打开 复制 │ res 包 图片 │ ▶运行 格式化│
├────┬─────────────┬───────────────────────────────┬───────────────────┤
│图标│ 左面板      │  画布舞台                     │ 属性面板          │
│条  │ (视图内容)  │  ┌─────────────┐              │ [选中: TextView]  │
│52px│ 240–280px   │  │  手机外壳   │              │ ├ 布局            │
│    │             │  └─────────────┘              │ ├ 外观            │
│    │             │  缩放 HUD 右下                 │ ├ 文本            │
├────┴─────────────┴───────────────────────────────┴───────────────────┤
│ 状态条：当前文件 · 设备 · 缩放 · 问题数（点击→问题面板）             │
└──────────────────────────────────────────────────────────────────────┘
```

**缺的东西（建议补）**：
- **底部状态条**（现在没有）：文件路径、设备、缩放、lint 问题数、保存状态（已保存/未保存/保存中/上次保存时间）。开发工具没有状态条会一直让人心里没底。
- **顶部文件标签栏**（像 IDE 的 tab）：最近打开的 layout 横向排开，可关闭、可拖动排序。现在换文件要靠项目树，来回跳很累。
- **问题面板**（底部可收起抽屉）：lint 结果列表，点一条跳行。现在只有「N 个问题」的角标。

### 1.2 响应式断点

| 宽度 | 布局 |
|---|---|
| ≥1280 | 三栏常驻（左 280 + 画布 + 右 320） |
| 900–1279 | 左右栏默认收起，浮层覆盖画布（已有 slide 机制） |
| <900 / 手机 | 底部 tab（预览 / 代码 / 属性），顶栏精简为 4 个图标 + 溢出菜单 |

**手机端现状问题**：底部工具栏按钮 7 个平铺易误触（res 包/运行挨着），需要主次：`▶ 运行` 主按钮（填充色）+ 保存图标 + 溢出「⋯」。

## 2. 顶栏 Toolbar

### 2.1 分区（从左到右，语义分组，组间细分隔线）

1. **工程组**：侧栏开关（左右）、设备选择（带尺寸副标题，如 `Pixel 5 · 393×851`）
2. **视图组**：缩放滑杆 + 百分比数字（可点开预设 50/75/100/适配）+ 适配屏幕按钮
3. **编辑组**：撤销、重做（禁用时降低到 40% 不透明，并给 title 说明「已到最早」）
4. **文件组**：保存（主色按钮，未保存时显示小圆点）、打开文件、另存为、复制导出 XML
5. **资源组**：res 包导出、图片导出（下拉：PNG 2x / PNG 3x / SVG）
6. **运行组**：▶ 运行（强调色）、格式化

### 2.2 必须改的细节

| 现状 | 问题 | 建议 |
|---|---|---|
| 全部图标按钮等权 | 保存和导图长得一样重 | 保存=主按钮；导出类=图标+文字；其余=图标 |
| 缩放滑杆无刻度 | 拖到哪算哪 | 加 3 档吸附（50/100/150）+ 双击数值恢复 100% |
| 设备下拉只有名字 | 不知道尺寸 | 两行：名称 + `393×851 · 420dpi`；顶部搜索框 |
| 无「未保存」提示 | 关页面丢改动 | 标题栏 `•` + 状态条 + beforeunload 拦截 |
| 移动端 7 键平铺 | 误触 | 主按钮 1 + 图标 2 + 溢出菜单 |

**快捷键**：`Ctrl/Cmd+S` 保存，`Ctrl+Shift+S` 另存，`Ctrl+Z / Ctrl+Shift+Z` 撤销重做，`Ctrl+O` 打开，`Ctrl+E` 导出图片，`F5` 运行，`Ctrl+Alt+L` 格式化（对齐 AS）。

## 3. 左侧图标条 LeftRail（52px）

现状 7 个入口：组件 / 图层 / AI / 已生成资源 / 项目管理 / 设置 / 关于。

**建议**：
- **按使用频率重排**：组件、图层（编辑时 90% 时间在这两个）→ 项目管理、已生成资源、AI（次频）→ 设置、关于（低频，收到最底部）。
- **加 tooltip 延迟 400ms**（现在靠原生 title，慢且丑），并显示快捷键（`1`~`7` 直接切换）。
- **加未读/状态点**：AI 生成完成 → 图标角标；项目有外部改动 → 红点。
- **关于**不该占一级入口（低频），收到设置面板底部或用户菜单。
- 图标条本身支持**折叠成 0**（现在只能收起整个左面板，图标条跟着消失？确认：应是面板收起则整条消失 → 建议图标条常驻，面板可独立收起，这样切视图不用先开面板）。

## 4. 组件面板（parts）

### 4.1 现在有什么
搜索框 + 按 lib 分组（Material3 / Classic 等）+ 拖到画布。

### 4.2 该有的（按价值排序）

1. **常用置顶**：本地记录使用频次，前 8 个做「最近使用」横排（图标 40px），减少找控件的心智成本。
2. **搜索增强**：支持别名（搜「按钮」出 Button/MaterialButton/ImageButton；搜「divider」出 MaterialDivider）；匹配到拼音首字母；结果里高亮命中片段。
3. **拖拽预览**：拖动时浮标显示「控件名 + 默认尺寸」，画布上显示落点插入线（现在只有高亮容器）。
4. **双击 = 插到当前选中容器内**（不用精确拖放，这对触屏和小屏特别重要）。
5. **分组可折叠 + 分组内计数**；折叠状态记忆。
6. **每个控件项 hover 出「?」**：一句话说明 + 最小可用属性示例（如 `ConstraintLayout` 提示「建议作为根节点」）。
7. **空态**：搜索无结果时给出「没找到 X，试试：Button / TextView / LinearLayout」+ 清空按钮。

## 5. 图层树（layers）

### 5.1 现在
树形、展开折叠、锁定、上下移、删除、拖拽移动。

### 5.2 该有的

| 功能 | 为什么 |
|---|---|
| **顶部搜索/过滤框** | 30+ 节点后靠肉眼找是灾难 |
| **同步高亮 + 自动滚动** | 画布点选后，树要滚到可见并闪一下（缺） |
| **双目图标（显示/隐藏）** | 现在只能删除或锁定；希望临时 `visibility=gone` 预览效果 |
| **右键菜单** | 复制/粘贴/包裹进容器/提取为 include/删除，比底部小按钮强 |
| **拖拽插入线** | 现在拖到哪算哪，必须显示「会成为谁的子节点、插在第几个」 |
| **路径面包屑** | 树顶部显示 `LinearLayout > CardView > TextView`，点击可跳 |
| **节点类型角标** | 用 `T`/`B`/`C`（Text/Button/Container）小字母替代一长串标签，缩进更深也不挤 |
| **id 缺失提示** | 无 `@+id` 的节点显示灰色 `no-id`，点一下就地生成（约束布局必需） |
| **锁定/隐藏视觉区分** | 锁定=灰+锁图标；gone=斜体+50% 透明 |

**移动端**：树的行高 44，操作按钮收进每行右侧「⋯」。

## 6. 属性面板 Inspector（右）

这是**使用时长最长的面板**，值得单独设计。

### 6.1 结构建议

```
选中项头：  [图标] TextView  #title    ⟳ 重置   ⋯
            ← 面包屑：LinearLayout > TextView
[搜索属性…]                     [只看已修改]
├ 布局（常用前 6 个直接铺开）
│  宽 ▾ [match_parent]  高 ▾ [wrap_content]
│  外边距  ┌上 8 右 8 下 8 左 8┐ (四向联动切换)
│  重力 ▾
│  ▸ 更多布局属性（12）
├ 外观
│  背景  [色块▉] [@drawable/bg_card] [🎨]
│  圆角  8dp   内边距 16dp
├ 文本
│  内容 [Shop Home          ]
│  字号 16sp  颜色 ▉
├ 约束（ConstraintLayout 子项才有）
│  上下左右对齐可视化 + 偏移滑杆
└ 高级（不常用的折叠，默认收起）
```

### 6.2 关键交互

1. **分组折叠 + 「更多」折叠**：常用 6–8 个属性直接可见，其余折叠，避免面板一屏 40 行。
2. **属性搜索**：输入 `margin` 显示所有外边距相关，**跨分组**呈现结果。
3. **「只看已修改」开关**：真实项目里 80% 属性是默认值，这个开关直接减半噪音。
4. **每行三态**：默认值（灰）/ 已修改（主色左竖条）/ 无效值（红边 + 说明）。
5. **值编辑器按类型给最合适的控件**：
   - 尺寸：数字 + 单位下拉（dp/sp/px/%），常用值 chips（`match_parent` `wrap_content` `0dp`）
   - 颜色：色板 + eyedropper + `@color/` 引用切换（硬编码时提示「提取为 @color」）
   - drawable：缩略图 + 选图标/形状 + 「编辑」
   - enum（gravity/orientation）：分段控件而非下拉（少一次点击）
   - boolean：开关；维度组（margin/padding）：四向输入 + 锁链联动
6. **行内错误**：`0dp` 在非 ConstraintLayout 下、`match_parent` 用在 weight 场景等 → 就地黄色提示，不弹窗。
7. **重置单属性**：hover 行尾出现 ↺，一键回默认。
8. **键盘**：Tab 顺序 = 视觉顺序；Enter 提交，Esc 还原；`↑/↓` 在数值上 ±1，`Shift+↑` ±10。
9. **空态**：现在是「在画布或图层树上点任意控件…」，建议加两个快捷入口：「插入组件」和「打开图层树」。

## 7. 画布舞台 CanvasStage

### 7.1 该有的操作反馈

| 场景 | 需要 |
|---|---|
| 悬停控件 | 1px 蓝色描边 + 左上角尺寸标签 `120×48`（现在无尺寸标签） |
| 选中 | 8 个手柄 + 尺寸标签 + 边距可视化（选中控件到父容器的 margin 用橙色区块显示） |
| 拖动 | 落点插入线 + 与兄弟控件对齐虚线 + 八像素吸附提示（`8dp` 小标签） |
| 缩放 | 右下角 HUD 显示 `100%`，拖动画布空白处平移，`Ctrl+滚轮` 缩放 |
| 拖到画布外 | 出现「松开删除」提示区 |
| 空布局 | 中间放「从左侧拖入组件」+ 「用空白模板开始」 |
| 解析失败 | 已有卡片：原因 + 「去代码面板修正」 ✅ 保持 |
| 结构警告 | 已有黄条 ✅ 保持，补「点击定位」 |

### 7.2 画布外围该补的

- **标尺/参考线**：顶部与左侧 8dp 刻度尺，可拖出参考线（桌面端很有用）。
- **多设备并排预览**：切换按钮「单机 / 双机对比」，做响应式时刚需。
- **画布右下浮动工具**：缩放 +/−、适配、镜头（截图当前视图）。

## 8. XML 代码视图

现状：行号、高亮、错误行标记、焦点跳行、底部工具栏（格式化/示例/打开/保存/res 包/运行）。

**补充建议**：
1. **双向定位**：画布选中 → 代码自动滚到对应元素并高亮（现在只有 gotoLine 的入口，缺反向）。
2. **行内错误 gutter**：错误行左侧红点，hover 显示原因；点击跳到属性面板对应项（闭环）。
3. **折叠**：容器节点可折叠（大布局必需）。
4. **编辑器工具栏精简**：格式化和保存移回顶栏，这里只留「示例项目 / 打开 / 运行」——避免两套按钮重复。
5. **查找替换**（`Ctrl+F`）：只在当前文件，带「仅替换选中范围」。
6. **只读区标记**：include 展开的片段用浅色底纹，鼠标悬停提示「来自 xxx.xml」。

## 9. 运行调试视图 RunPreview

现状：涟漪、输入、开关、SeekBar、Spinner、列表假数据。

**该补的**：
- **工具栏**：设备切换、深浅色、语言（中/英）、「显示热区」开关（高亮所有可点区域，教人知道哪些能点）。

- **数据注入面板**：长文本/空列表/加载中/错误态一键切换，用来验布局鲁棒性（这是设计稿工具做不到的差异点）。

## 10. 项目管理 ProjectPanel

现状：项目列表（4s 轮询）+ 打开目录 + 新建项目 + 结构树（异步加载）+ 资源片段编辑。

**建议**：
1. **列表卡片化**：每个项目显示「图标（自动分析 app icon）+ 名称 + 路径 + layout 数量 + 最近修改时间」，hover 出「打开目录 / 在树中展开」。
2. **搜索 + 最近打开置顶**（现在没有搜索）。
3. **结构树**：
   - 资源目录分组（layout / drawable / values / mipmap），每组显示数量
   - 文件名右侧显示「被引用次数」，点击看谁引用（后面能力）
   - 双击打开；单击选中 + 顶部显示路径
   - 「新建 layout / 复制布局 / 重命名」右键菜单
4. **空态**：没有项目时给「选择一个文件夹（推荐 Android 项目的 res 目录）」+ 一句说明 + 示例项目入口。
5. **轮询可见化**：4s 轮询用户不知情 → 状态条显示「已同步 3 个文件」（轻提示，不打扰）。
6. **冲突提示**：外部改动时行内黄点 + 「重载此文件」。

## 12. AI 助手 AiPanel

现状：5 家预设、key 本地存、带当前 XML 上下文、回复里 XML 可一键替换。

**建议**：
1. **上下文可视化**：发出去之前显示「已附带：当前 XML（306 行）+ 选中节点 `#title`」，可关闭附带。
2. **应用策略三选**：整份替换 / 只替换选中子树 / 只看不应用（diff 模式）。默认「只替换选中子树」更安全。
3. **diff 预览**：应用前显示 +/- 行，确认才写入（关键信任点）。
4. **预设提示词 chips**：「加个底部导航」「这屏太挤，优化间距」「换成暗色配色」「生成空态页面」。
5. **失败可读**：401/404/429/超时/跨域 → 人话 + 「去设置填 key」按钮（已有部分，补 429 重试倒计时）。
6. **历史**：最近 10 次对话可回看（localStorage），避免关掉就没了。

分组：外观（主题/语言/暗色）、编辑器（缩进/自动格式化/保存时格式化）、预览（设备/系统栏/显示问题条）、AI（服务商/key/模型）、工作目录（路径/更换/重置）、关于（版本/仓库/反馈）。

## 14. 弹窗族统一规范

| 弹窗 | 必要元素 | 现状问题 |
|---|---|---|
| 保存/另存 | 文件名（带 `.xml` 后缀提示 + 合法性实时校验）、路径预览、主按钮「选择文件夹并保存」 | 缺文件名校验；缺「将写入哪些文件」摘要 |
| 新建项目 | 项目名（实时预览包名/目录结构）、模板选择（空/登录/列表）、创建 | 只有名字，缺模板 |
| 新增属性 | 搜索 + 按类型分组 + 最近使用 + 常用推荐 | 建议默认聚焦搜索框 |
| 导出检查 | 问题列表（点跳行）+ 模式切换 modern/compat + 导出 | 已有，补「忽略此问题」 |
| 导出图片 | 倍率（1x/2x/3x）、背景（透明/白/自定义）、格式 | 补实际尺寸预览 |
| 形状编辑器 | 实时预览 + 常用预设（卡片/圆角按钮/椭圆/分隔线） | 补预设 |
| 图标编辑器 | 图标网格（可搜）+ 单色/多色 + 尺寸 | 补搜索 |

**统一行为**：Esc 关闭、点击遮罩关闭（除保存类）、Enter 确认、焦点自动落第一个输入、打开时锁定背景滚动、关闭后焦点回到触发按钮。

---

## 15. 全局提示系统（Toast / 通知）

现状：`exportNote` 一行文本，2.4–5s 自动消失。

**建议升级为 toast 组件**：
- 位置：底部中间（移动）/ 右下（桌面），不挡属性面板
- 类型：success（绿勾）/ info / warn（黄）/ error（红）
- **带动作**：`已删除 TextView` + [撤销]（3s 内可点）
- 同类折叠：连续保存只留最新一条，不刷屏
- 长文本可展开（错误详情）

---

## 16. 可发现性与引导

1. **首次使用**：3 步引导（左选组件 → 中拖放 → 右改属性），可跳过，`localStorage` 记住。
2. **空项目页**：三个入口卡片——「空白布局」「示例项目」「打开我的项目」。
3. **「?」帮助**：每个面板标题右侧一个问号，弹小卡（含 3 条要点 + 快捷键）。
4. **命令面板 `Ctrl+K`**：搜「导出 png」「切 Pixel 6」「格式化」——进阶用户的加速器，也是功能可发现性的兜底。

## 18. 与功能路线图的衔接

- 上面第 1–5 项属于「UX 地基」，建议排在功能 M26（往返保真）之后、M27 之前做，约 **4–6 人日**。
- 属性面板搜索/只看已修改，正好是 M28（values 资源管理）的前置——做了它，色值/尺寸管理才有地方挂。
- 文件标签栏是 M29（include 可编辑）的前置——多文件跳转没 tab 会很痛苦。
- 命令面板放三阶段（M38），但它能让所有新功能「可被发现」，越早越好，可视精力提前。

---

_结论：现在这套 UI 的骨架是对的（三栏 + 左右面板 + 顶栏），缺的主要是「联动、状态反馈、可发现性」这三类细节。上面第 1–5 项加起来不到一周，做完体感会从「能用的网页」变成「像样的工具」。_
