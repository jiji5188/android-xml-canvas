M154：真机渲染搭桥（编辑器 → 设备端 aapt2 → 系统 LayoutInflater）

原来只能在电脑上跑 foundation 的 PoC，手机上点不了。这次把桥接起来：

原生（MainActivity）
- 新增 AxvNative.renderReal(id, payloadJson)：后台线程把 payload 的 res 文件写成树，
  用 nativeLibraryDir 里的 libaapt2.so 现场 compile + link（--package-id 0x80），
  成功后启动 PreviewActivity；结果通过 window.__axvRender(id, json) 异步回传
- 新增 quote/deleteTree/writeUtf8/runAapt2 小工具；只收 res 内相对路径（挡 .. 和绝对路径）

PreviewActivity
- 改成吃 Intent 参数：apk / pkg / layout（不传就是原来内置的 demo 资源包）
- 真机渲染模式下隐藏调试头，只留真控件；失败时才把堆栈显示出来
- 内置 demo 专属的 wrap_clip/wrap_scale level 设置只在 builtin 时做

Web
- lib/xml/native-render.ts：hasRealRender() + renderReal(layoutName, files)，
  带 25s 超时、按 id 派发回调、WebView 刷新后自动重挂 __axvRender
- Toolbar 新增「真机渲染」按钮（只有 APK 里有桥才显示），busy 时置灰防连点
- XmlEditor：doRealRender 用 currentSaveInput() + buildSaveFiles() 复用四路保存的产物，
  成功后提示「N 个文件 → 资源包 X KB（编译 Y ms）」，失败按 compile/link 阶段区分

测试
